## 1. 结论先行

- 竞品 = 「直播平台自有引擎」全家桶（视频直播/推拉流 + 悬浮窗 + 抖音弹幕直连 + 直播位 + 邀请分销 + 白标）；

### P0 · 与商业闭环强相关（优先立项）

| 任务 | 解决 | 前置/阻塞 | 建议做法 | 验收口径 |

## 6. 推进建议

1. **先做能脱离外部资源的**：R6（降本，纯服务端）与 R1/R4/R2（直播间配置，纯代码）可先行，逐批 ≤500 行。
2. **并行等外部资源**：R7 等支付宝凭证；凭证期间不阻塞 R6/R1。
3. **运营化在 P0 后**：R8（自更新）建议紧接 P0，避免云端发版靠手动重装。
4. **增长与 OEM 放在收款与租户模型之后**：R10~R12 依赖 R7/R11，避免前置返工。
5. 本清单与 `docs/LOWCOST-AUDIO-PLAN.md`、`docs/console-roadmap.md`、`docs/PROGRESS.md` 联动追记；新批次命名沿用既有前缀（T/M/G）或开「竞品补差」系列。
