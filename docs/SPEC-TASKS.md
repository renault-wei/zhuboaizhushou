### 1.2 目标

把「AI 语音轮播 + 话术讲解」主链路的**每小时成本压到可售卖区间（≤ 0.4 元/小时）**，同时补齐**直播中欠费暂停**与**话术完整性**两个直接影响可用性的缺口。

### 1.3 范围边界

- **做**：服务端缓存旁路、首轮预热、用量计量接线、直播中欠费闸门、话术字数与节奏口径落地。
- **暂不做**：数字人、多平台推流、多门店、托管式实时弹幕互动、App 内支付 SDK、抖音 wss 直连。
- **附注**：弹幕抓取需求已关闭，不在本批范围。

### 1.4 约束（AGENTS.md）

- 直播画面必须叠加「AI 智能直播」角标，且**不可关闭**。
- 克隆音色前必须签《声音授权协议》并存档；话术开播前做敏感词扫描。
- 第三方 AI 调用先查额度，超额拒绝并引导续费；**密钥只走 `.env`**。
- DB 变更必须写 `server/drizzle` 迁移；TS / Dart 严格模式；单批改动 ≤ 500 行。
- 不搬运竞品代码，仅参考结构 / 交互 / 文案。

### 1.5 验收口径

- **缓存**：同（音色 + 语速 + 文本）第二次合成**零供应商调用**；写缓存失败不影响出声。
- **计量**：命中不写 `usage_logs`、不扣额度；只有真实新合成才记账。
- **闸门**：余额与免费分钟同时耗尽时**只停口播、不停画面**，并给出续费提示。
- **话术**：**无字数硬上限**；用户自带话术不删字、不截断、不被拒绝保存。
- **播放连续性**：一段话术出声过程中**不得出现句中停顿**（长文本由合成层内部处理，听感为整段）。
- **成本**：每小时新合成字符 ≤ 2000（锚点值）。

## §4 已拍板口径（2026-09-16）

1. **话术字数：打开 200 字限制。**
   - 用户自带话术不再因超 200 字被拒绝：`server/src/routes/loopScripts.ts:94` 的硬校验取消。
   - 用户话术**不删字、不截断、不自动切段**（与既有产品要求一致）。
   - AI 生成侧保留一个宽松安全上限，仅用于拦截模型异常输出，不作为用户内容限制。
   - 触发风险：`volcTTS` 目前把整段 text 一次性提交（`server/src/services/volcTTS.ts:271`），若超长文本触及单请求上限，需在**合成层内部**处理（合成后拼接为单段音频），对外听感仍是一整段、不出现句中停顿。
2. **欠费暂停形态：只停口播。**
   - 余额与免费分钟同时耗尽时，仅停止 AI 语音的新合成与播放，**画面与推流继续**（适配真人主播在场的场景）。
   - 工作台持续展示续费提示；续费到账后自动恢复口播，从下一条继续。
3. **支付：保留口子。**
   - 本轮不接真实支付通道，只预留服务端查单接口与订单数据结构，保持「服务端主动查单 + 订单号金额核对 + 幂等」的设计位。
   - 现有收款方式不变（人工转账 / 卡密核销）。个人主体资质问题**不再阻塞**任何开发任务。

### 待复核（不阻塞开工）

- 火山 TTS 单次请求的文本长度上限实测值；若小于用户可能输入的长度，则 A5 需补「合成层内部分段 + 拼接」实现。
