## 1. 目标与口径（承接 docs/PLATFORM-NEUTRAL-VOICE.md §4.1）

| 指标 | 目标口径 | 说明 |
|---|---|---|
| 每小时成本 | **≤ 0.4 元/小时** | 固定循环台本场景，含 DeepSeek 文案 + 火山 TTS 新合成；达标以云端实测入档 |
| 每小时新合成字符 | **≤ 2000 字符** | 首轮预热 + 台本改动 + 弹幕回复限流插入之外的循环全部命中缓存 |
| 命中路径 | 循环台本首轮预热 → 缓存全命中 | 命中即旁路火山 TTS，不产生真实费用 |
| 现状基线 | 每轮全量重合成 ≈ 4 元/小时 | 见前轮成本核算；本里程碑把缺口从「×10 单价差」压回锚点内 |

- 商业含义：按直播分钟 / 算力对商家收费要留毛利，前提是把**单位小时真实新合成量**压到足够低。
- 只针对「可预期重复」的语音：固定台本循环、模板化开场/过品/逼单句。弹幕回复天然不可预期，用频控与自然停顿插入收口（我方既有口径）。

## 3. 缓存设计草案（仅设计图，非 DDL 执行）

- 缓存键（必须覆盖的维度）：`voiceKey + rate + textSha256`。
  - `voiceKey`：克隆音色 = `voiceId`；火山预设 = `volcPresetId`（二者互斥，取值口径对齐 lives 的既有归一）。
  - `rate`：语速 / 停顿参数（预设音色与克隆音色各自带语速档）。
  - `textSha256`：台本条目文本 sha256（改一个字即 miss，天然处理改稿失效）。
- 新增表（草案）：`tts_audio_cache` —— `id`、`user_id`、`voice_key`、`rate`、`text_sha256`、`text`（原始文本，便于排查）、
  `audio_path`（产物文件相对路径，同现有 wav 临时文件目录体系）、`chars`、`hit_count`、`created_at`、`last_hit_at`。
  设计要点：**按 user 隔离**（克隆音色属个人资产）；预设音色可后续升级为全局共享缓存（多用户复用同一段预设音色音频）。
- 行为约定：
  - `speak()` 命中 → 直接返回音频路径，不调供应商、不写 usage_logs、不扣 ttsCharsUsed。
  - miss → 合成成功后原子写缓存 + usage_logs（仅记真实合成），失败不影响既有出声链路（写缓存失败只告警）。
  - 缓存淘汰 / 上限：v1 不做 LRU 复杂度，先按「每个 user 缓存条目数上限 + 按 last_hit_at 懒清理」兜底，防无限膨胀。
- 旁路开关：`TTS_CACHE_ENABLED`（默认开）与 `TTS_CACHE_DRY` 不入库只打点（用于灰度对比命中率），配置只走 `.env`。

## 4. 里程碑与验收口径

### T3 · TTS 分句缓存（服务端）
- 改动面：`liveSpeaker.speak` 前插缓存旁路 + 新表 drizzle 迁移 + 缓存读写服务（含单测替身不真调火山）。
- 验收：同一（音色 + 语速 + 文本）第二次 `speak` 命中缓存，供应商调用数不增；单测覆盖 miss→合成入库 / hit→旁路 / 缓存键互斥归一 / 写缓存失败不阻断出声。
- 单测要求：`liveSpeaker.test.ts` 扩展用例，用 stub 供应商断言调用次数。

### T4 · loopCaster 首轮预热
- 改动面：场次 `start` 进入循环前，对绑定的 loopScript 全部条目执行一次预合成写缓存（复用 T3 缓存写路径，失败降级为边播边合成）。
- 验收：开播后整轮循环口播不再触发新合成（预热完成）；预热不阻塞 `start` 返回（后台任务 + 状态可查）。
- 单测要求：`loopCaster.test.ts` 断言预热后循环 speak 全部命中、供应商零调用。

### T5 · usage_logs 计量接线（只计真实新合成）
- 改动面：把缓存 miss 的真实合成按 `category='tts'` 记账（outputChars = 实际合成字符，costCents = 实际价），hit 不记账。
- 验收：跑 1 轮循环台本后 usage_logs 只出现首轮预热条目；命中率可用 usage_logs 反推。
- 单测要求：计量用例断言 hit 不写流水、miss 写且扣额度。

### T6 · 云端成本实测（外部依赖）
- 前置：云端 ECS（113.44.226.189）部署 T3~T5 代码 + 火山已充值 key（可真实计费）；本地 Windows 开发机只做联调不做计费基准。
- 验收：固定循环台本实跑满 1 小时，账实核对（usage_logs sum(costCents) + 火山账单）≤ 0.4 元/小时、每小时新合成 ≤ 2000 字符；实测结论追记回本文档与 PROGRESS。
- 说明：T6 是唯一需要真实第三方费用的里程碑；T3~T5 单测与本地验证不得真调第三方。

### T7 · 观察项（不入代码）
- 命中率仪表：公司端任务台后续展示「缓存命中率 / 每小时新合成字符」两指标（对齐 console-roadmap 计量页）。
- 预设音色全局共享缓存：多商家同用一预设音色时按 voice_key 去 user 维度，作为 v2 降本选项。
- 弹幕回复缓存：高频问题（如「多少钱 / 怎么买」）可复用回复音频，属观察项、v1 不做。
