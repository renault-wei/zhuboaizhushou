# 开发排期 — Sprint 计划（V1.0）

> 基准：2.5 人团队（1 全栈 + 1 前端 + 0.5 产品/测试），AI 辅助开发（Codex + DeepSeek）
> 原则：每个 Sprint 结束都有**可演示**的东西；推流（最大风险）安排在中间而非最后

---

## 总览

| Sprint | 时间 | 主题 | 演示物 |
|---|---|---|---|
| S0 | 3 天 | 环境与脚手架 | 空壳 App + 后端跑通 + 后台跑通 |
| S1 | 2 周 | 登录 + 声音克隆 + 话术生成 | 手机上录音→克隆→生成话术全流程 |
| S2 | 2 周 | **直播推流核心**（生死线） | 真机开播：实景循环+券贴纸+角标 |
| S3 | 2 周 | 支付 + 额度 + 后台管理 | ¥99 支付闭环 + 运营可管 |
| S4 | 1 周 | 联调 + 修 Bug + 提审 | 应用市场提审包 |

合计 **8 周 + 3 天**（对应开发计划 W3–W10）。

## 附录：数据库核心表（S0 定稿用）

```
users          用户（手机号/抖音绑定/订阅状态）
voices         音色（provider_voice_id/授权协议存档路径/样本指纹）
scripts        话术（行业/商品快照/内容/敏感词扫描结果）
lives          直播记录（画面源/券ID/音色/话术/开始结束/状态）
orders         订单（微信支付单号/金额/状态）
quotas         额度（TTS字符/话术次数/直播分钟数，月度重置）
usage_logs     用量流水（每次AI调用一条，含成本）
admin_users    后台管理员
audit_logs     审计日志
```

## Git 仓库说明

- **本地开发不需要 Git 账户**——仓库已初始化在 `D:\星辰语音App\06-代码\starvoice`
- 需要账户仅当：① 云端备份防丢盘 ② 多人协作 ③ CI
- 推荐：注册 **Gitee**（国内快、免费私有仓）或已有 GitHub 账号也行
- 有了远程仓库后推送命令：`git remote add origin <地址> && git push -u origin master`
