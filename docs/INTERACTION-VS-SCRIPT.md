## 1. ① 互动阻碍话术 —— 机制与量化

### 1.1 机制（代码事实）

`services/loopCaster.ts:301` —— 每句台本之前：

```ts
// 空档避让：出声链路忙（回复排队 / 远程积压）→ 小步轮询，不在播放间隙插队
while (!state.cancelled && options.isBusy(liveId)) {
  await options.sleep(idlePollMs);
}
```

`defaultIsBusy` = 该场次出声链路**未播出的排队条数 > 0**。

而 `loopCaster.ts:187` 的注释把设计意图写得很明白：

> 回复由 liveSpeaker 队列**天然优先** —— 链路忙（回复排队/远程积压）时本轮机会直接让位，不排队抢播。

**所以「回复优先、台本让位」是刻意的。问题在于：这个 while 没有超时、没有配额、没有「台本至少播多少」的保底。**

### 1.2 量化：什么条件下台本会被饿死

设：回复间隔 `T`（账号设置，可 1~60 秒）、单条回复音频时长 `L`。

- `L < T` → 队列能在两次回复之间排空 → 台本有播放窗口 ✅
- **`L > T` → 队列永远排不空 → 台本**永远**播不了** ❌（回复持续入队，链路恒忙）

`L` 的估算：默认语速档 -10 ≈ **4.7 字/秒**（见 `20260911_v09` 迁移注释），一条 20~40 字的回复 ≈ **4~9 秒**。

**而账号设置的默认值是 5 秒/次 —— 已经贴着临界线；App 里还提供了「1 秒/次」这一档，选它等于直接把台本关掉。**

### 1.3 为什么这条值得重视

商家开播的**核心诉求是循环台本讲商品**。如果台本被互动挤停，等于**主要功能失效**，而界面上**没有任何提示** —— 商家只会觉得「今天 AI 怎么不说话了」。

## 2. ② 弹幕过多 —— 现状与可选策略

### 2.1 现状（代码事实）

`services/interactionEngine.ts` 的判定顺序：

```
空弹幕 → 场次不存在 → 非直播中 → 回复已关闭
  → 场次级频控（GLOBAL_THROTTLED，直接丢弃）
  → 用户级频控（SENDER_THROTTLED，硬编码 5s）
  → 固定回复匹配（FAQ）
  → AI 生成
```

三个事实：

1. **没有任何待回队列** —— 窗口内的弹幕**直接丢弃**，不是「稍后回」，是**永远不回**。
2. **没有优先级** —— 一条真问题和一句「哈哈」在频控面前完全等价，**谁先到谁占名额**。
3. **固定回复也受频控** —— 频控判定在 FAQ 匹配**之前**，所以**零成本的固定回复也会被丢弃**。

### 2.2 可选策略（供拍板）

| 方案 | 做法 | 代价 | 我的看法 |
|---|---|---|---|
| **A 问题识别** | 只对「像提问」的弹幕回复（含 ？/吗/怎么/多少/能不能 等），灌水直接丢 | 规则误判；但**极便宜** | ✅ 性价比最高 |
| **B 优先级队列** | 待回弹幕排队，按优先级取；队列有上界，满了丢最旧的 | 要新增状态与淘汰策略 | ✅ 与 A 叠加效果好 |
| **C 同类合并** | 多条同义问题合成一条（「好几位朋友都在问多少钱…」） | 需要聚类，复杂度高 | ⚠️ 二期再说 |
| **D 固定回复免频控** | FAQ 命中不受间隔限制（反正不花钱） | 可能被刷屏重复同一句 | ✅ 但需要配「同一条最短重复间隔」 |
| **E 覆盖率可见** | 监控页显示「本场收到 N 条 / 回复 M 条」 | 纯展示，几乎零成本 | ✅ **强烈建议先做** |

### 2.3 一个必须澄清的产品问题

**「不可能所有都回复」商家是否知情？** 现在**完全不知情** —— 界面上没有任何地方显示丢弃了多少。
→ 建议至少做到 **E**：把「回复覆盖率」摆在台面上，让商家自己判断频次要放松还是收紧。

## 4. 待你拍板

❓ **D1 · 台本要不要保底？**
现状是回复优先、台本无保底。➡️ **推荐要**：给让位加一个上限（比如「连续让位超过 30 秒就强制播一句台本」）。
**理由：商家的核心诉求是讲商品，互动是点缀 —— 点缀不该把主线挤没。**

❓ **D2 · 保底口径怎么定？**
候选：**(a)** 时间口径（让位超 N 秒强制播一句）｜**(b)** 比例口径（台本占比不低于 X%）｜**(c)** 优先级口径（台本句优先级高于普通回复，但低于固定回复）
➡️ **推荐 (a)** —— 最好实现、最好解释、商家一看就懂。

❓ **D3 · 问题识别用什么？**
**(a)** 纯规则（关键词 + 问号）｜**(b)** 规则 + 长度启发式｜**(c)** 让 AI 判（贵）
➡️ **推荐 (b)** —— 便宜且够用；AI 判定要额外花钱，不值得。

❓ **D4 · 固定回复要不要免频控？**
➡️ **推荐免**（它不花钱、也不占 AI 配额），但**必须配一条同条最短重复间隔**（比如同一问法 60 秒内不重复答），否则会被刷屏。

❓ **D5 · 覆盖率要不要做？**
➡️ **推荐做**，而且**最好先做** —— 它是 D1~D4 的判据：不显示覆盖率，商家根本不知道自己的设置是不是太紧。
