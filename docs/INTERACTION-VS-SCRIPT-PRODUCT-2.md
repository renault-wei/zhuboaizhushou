## 1. 先说一个我刚查清、且必须马上告诉你的事实

**现在的无效弹幕，不只是「没被过滤掉」——它既花钱、又占位。**

判定顺序（代码事实）：

```
① 时间窗限流  ← 灌水在这里抢名额
② 固定回复匹配
③ 调 LLM 判断「这条要不要回」  ← 灌水在这里被判 NONE
```

**后果有两层，第二层更疼：**

1. **占位**：一句「666」抢走时间窗名额，把真问题挤掉（真问题直接消失，永不再来）
2. **花钱**：灌水照样**触发一次 DeepSeek 调用**，模型读了半天返回 `NONE` ——
   **我们花钱买了一句「不说话」**

按默认 5 秒/次算，一分钟最多 12 次 LLM 调用。**一个灌水为主的直播间，大部分钱花在了「决定不回答」上。**

## 2. 所以产品规则应该是三层（顺序是重点）

### 第一层：**有效吗？**（挡在门外，不占任何名额、不花钱）

| 判定 | 处置 |
|---|---|
| 纯表情 / 刷屏 / 灌水（666、哈哈哈、来了） | **静默丢弃** |
| 广告推销 / 辱骂 | **静默丢弃** |
| 与商品无关的闲聊 | **丢弃** |
| 疑问句 / 商品咨询 / 需求表达 | **放行** |

> **这一层必须在最前面。** 现在它在最后（而且前面已经被时间窗筛过一遍）。

### 第二层：**值得回吗？**（定优先级）

| 类型 | 优先级 | 说明 |
|---|---|---|
| 商品咨询（价格 / 套餐 / 到店 / 核销） | **高** | 直接关系成交 |
| 需求表达（「我想要」「能便宜吗」） | **高** | 已经想买了 |
| 问候（「主播好」） | 中 → **建议交给氛围语** | 见 §4 |
| 闲聊 | 低 | 有空档且额度没花完才回 |

### 第三层：**什么时候回？**（这就是节奏）

**节奏的硬保障 = 一个台本空档最多插一条互动。**

现在的机制是「链路忙台本就让位」，多条回复可以连续堆积 —— **没有「一个空档一条」这条规则**。
加上它，节奏就有了下限保障：无论弹幕多少，台本句之间**最多**夹一条互动。

## 3. 「节奏一定要好」需要变成**可验收的口径**

否则「好不好」没法判断、也没法回归。三个候选：

| 口径 | 含义 | 评价 |
|---|---|---|
| **(a) 配比** | 台本占出声时长 ≥ 70% | 可测，但**过程可能很难看**（比如前 10 分钟全是互动、后 20 分钟全是台本） |
| **(b) 句间隔** | 任意两条互动之间至少隔 N 句台本 | 简单，但 N 大了会**不及时**（问题等太久人走了） |
| **(c) 轮次完整性** | 每一轮台本必须**完整播完**，互动只在**轮与轮之间**插 | 新观众在任何时刻看到的都是**连续完整**的讲解 —— 认知最好建立 |

➡️ **我倾向 (c) 为主 + (b) 兜底**：
- **(c)** 保证「一轮商品讲解是完整的」—— 这是新观众形成认知的**最小单位**；被打断的一轮等于白讲
- **(b)** 防止「一整轮太长导致互动长时间不响应」（比如一轮 90 秒，那就在轮内也允许插一次）

## 4. 一个必须厘清的分工：**问候该归谁**

「主播好」「来了」这类，**既不是无效弹幕、也不该占互动名额** ——
因为它要的不是「回答问题」，而是「打招呼」。

**而打招呼我们已经有专门的机制：氛围语的「欢迎语」**（在空档插播 + 自己的频次控制）。

所以正确分工是：

| 弹幕类型 | 归属 |
|---|---|
| 商品咨询 / 需求表达 | **互动回复**（占互动名额） |
| 问候 | **氛围语·欢迎语**（占氛围语频次，不占互动名额） |
| 灌水 / 广告 / 辱骂 | **丢弃** |

> ⚠️ **但这里有个缺口**：氛围语的欢迎语目前是**按时间/空档**取词的，**不是「有人进场就触发」**。
> 进场事件（`WebcastMemberMessage`）已经能解码了，但**没有接到欢迎语上**。
> 要做这个分工，得先把「进场 → 欢迎语」这条线接起来（独立一张票）。

## 5. 修正后的目标状态（一句话）

> **台本完整地讲商品（一轮不被打断）；有效问题按优先级在空档插播（一个空档最多一条）；
> 问候交给氛围语；无效弹幕在门口就被挡掉，既不占名额也不花钱。**

## 6. 待你拍板

❓ **Q1 · 「有效」的判定口径**
候选：**(a)** 纯规则（问号 + 疑问词表）｜**(b)** 规则 + 长度启发式｜**(c)** 小模型分类（准但花钱）
➡️ **推荐 (b)**：规则能覆盖绝大多数，「便宜点吗」这种无问号的靠启发式补。
**但要你确认「有效」的边界** —— 尤其「闲聊」算不算有效（我倾向算低优先，而不是直接丢）。

❓ **Q2 · 节奏口径取哪个**
➡️ **推荐 (c) 轮次完整性为主 + (b) 兜底**（见 §3）。

❓ **Q3 · 无效弹幕要不要留痕给商家**
➡️ **推荐留计数、不留内容**：监控页显示「本场收到 N 条 / 有效 M 条 / 回复 K 条」。
让商家知道「今天灌水多少」，但不用看每一条。

❓ **Q4 · 问候交给氛围语（要新接一条「进场→欢迎语」的线）**
➡️ **推荐是** —— 否则「主播好」要么被丢（不礼貌），要么占互动名额（台本又被切）。

❓ **Q5 · 队列要不要上界、满了丢谁**
➡️ **推荐丢最旧的**（旧问题观众多半已经走了；新问题更值得答）。
