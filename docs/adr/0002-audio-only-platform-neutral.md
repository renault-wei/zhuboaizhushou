# 只出声：从「托管无人直播」转向「平台无关 AI 语音助播」

## Status

accepted（承接此前若干批次的口径修订，本次补齐决策记录）

## Context

项目立项时的定位是抖音专属的**托管无人直播**：合成画面 + 音轨 + 角标，推流到抖音 RTMP，商家不露脸、不出声。

推进中暴露出两件事，使这条路线代价过高：

1. **推流是单点阻塞**。它依赖抖音开放平台的企业资质与 key，长期拿不到，而它卡在整条链路的最末端——前面做得再多也无法验收。
2. **交付形态与客户不匹配**。目标商家普遍没有电脑、也不愿承担额外工具成本；而"画面"本来就可以由真人或实景承担，并不需要我们来合成。

## Decision

产品收敛为**平台无关的 AI 语音助播**：只负责直播间后台的**声音**——循环口播商品话术 + 针对弹幕做 AI 问答，**不出画面、不做推流**。

声音出口是一段与平台无关的音频，最终经音频注入设备被开播端当作麦克风采集。
平台相关性因此只剩"弹幕从哪来"这一处。

## Consequences

- 画面合成、RTMP 推流退出主链路；合规角标作为法规要求仍保留在系统内，但不再由"画面叠加"承担。
- 定位从"抖音专属"变为"平台无关"，商业模式随之从订阅制改为按直播时长 / 轮播量计费。
- 弹幕来源不再能靠自家推流链路顺带解决，成为**独立的外部依赖**；后续为此立过专项、又主动关闭过专项。
- 副作用：README 与技术栈表仍残留推流、订阅制等已被取代的描述，与现状不符。
