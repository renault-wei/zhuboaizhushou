> 定位 = 星辰语音 App 的**公司自营后台**（内部运营工具），
> 与商家手机 App / Windows 客户端并列的第三端，web 端只做内部运营用、不追求视觉（AGENTS.md）。
> 事实源：`docs/DEV-SPRINTS.md` S3（T15~T20）；数据表已就绪（orders/quotas/usage_logs/admin_users/audit_logs）。

## 1. 范围与边界

**做**（本方案 M1~M4，落地顺序 = 跑通自用闭环优先）：
- 公司账号登录（admin_users，只允许运营预置账号，**不开放注册**）
- 商家（租户）台账：手机号 / 订阅 / 注册时间 / 资源用量汇总
- 算力与额度：额度行查看与运营调整（月度周期），AI 用量流水查看
- 金额与订单：订单订阅列表、支付状态、运营补单（人工确权）
- 数据看板：北极星指标 = 商家数 / 订阅订单收入 / AI 用量 / 进行中直播
- 审计留痕：运营所有写操作进 audit_logs

**不做**（一期明确排除，避免冒进）：
- 商家自助注册 / 自服务改套餐（面向直客的收银台 UI 后续单独做）
- 真实微信支付证书对接（无商户号证书；本方案先走「运营人工确权」开发路径）
- 云部署 / 多租户隔离 / 计费单价配置页（本地自用验收后再说）
- 内容审核的“全自动放行”：仍按合规红线拦截，后台只做只读队列 + 授权存档

## 3. 服务端设计口径

- 鉴权：默认 JWT 保持商家端语义不变；新增 **admin 命名空间**（`@fastify/jwt` namespace），
  载荷只放 `{ adminId }`，每次请求回查 `admin_users` 有效在岗账号；杜绝商家 token 冒用后台。
- 口令：bcrypt 哈希只存 admin_users.password_hash；初始账号走 `npm run admin:seed` 脚本（env 读入，不留默认口令）。
- 额度：`quotas` 唯一键 (user_id, period)，period=YYYY-MM。商家首次调用第三方 AI 时按「免费试用档」自动建档
  （本自用阶段放量：TTS 字符 50 万/月、话术生成 300 次/月、直播 2 万分钟/月，数值可运营调整）；
  额度归零后返回 402 `QUOTA_EXCEEDED` + 引导续费文案（合规成本红线，不做关闭开关）。
- 用量：每次第三方 AI 调用成功写一条 usage_logs（category=script_generation 等；provider/model/promptChars/outputChars）；
  本地 mock / 本机 SAPI 不落成本金额（costCents=0，等接真实计费单价表再算）。
- 订单：商家 `POST /api/orders` 生成 pending（¥99/月=9900 分）；运营在后台「确认收款」= 模拟支付回调，
  把订单置 paid + 订阅顺延 30 天 + 当月额度按付费档刷新（幂等：重复确认 409）。

## 4. 后台页面清单（与侧边栏对应）

| 菜单 | 内容 |
|---|---|
| 数据看板 | 商家总数 / 本月新增 / 付费商家、订单与收入（本月/累计）、AI 用量次数与字符（今日/本月）、直播中/累计场次 |
| 商家管理 | 列表（手机号/昵称/订阅/创建时间/资源条数）+ 搜索 + 「额度调整」抽屉（读 used / 改 quota）+ 详情抽屉（额度历史/用量/订单） |
| 算力用量 | usage_logs 流水（用户/类别/字符/时间）+ 类别筛选 + 分页；顶部本月用量汇总卡 |
| 订单订阅 | 订单列表（订单号/商家/档位/金额/状态/时间）+ 状态筛选 + pending 行「确认收款」（Popconfirm） |
| 内容审核 | 三个 Tab：拦截话术队列（blocked scripts）/ 授权存档（voice_agreements）/ 审计日志（audit_logs） |
